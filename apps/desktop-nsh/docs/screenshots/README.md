# 桌面界面回归截图

截图分两批，**演示模式与真实隔离实例分开标注**，不拿演示数据冒充真实结果：

- P0 批次（01–10）：`target/release/moontv-native.exe` 0.3.0，Windows 11 x64，窗口固定 1707×945，深色主题。演示模式使用 `media/` 里生成的受控媒体（`testsrc2` 彩条 + 正弦音），没有连接任何真实实例。
- P1 批次（11–22）：0.4.0，同一台 Windows 11 x64 / 150% DPI，窗口 1707×945（客户端 1123×593 pt）。
  - **演示入口/演示数据**：11 是连接页（宽窗并排、含演示入口）；12–14 明确标「演示模式 / 演示数据」，番剧日历也是本机样例。
  - **隔离实例**：15–22 连接 `127.0.0.1:38080`（一次性 SQLite、端口与本地夹具源；见 `p1-contract-2026-11-24.md`）。搜索与 Bangumi 日历来自本地夹具；15/16/21 的豆瓣条目来自 `m.douban.com` 公网经实例代理读取，是外部数据，不是夹具，也不是用户的生产实例。

观察到的边界：

- 播放页按 `Esc` 只退出全屏，不退出播放器；返回要点头部的「返回」。截图流程按这个实际行为操作。
- 收藏卡片是 2:3 竖版，窗口高度固定时卡片会超出可视区，同步标记需要向下滚动才能看到；页面本身可滚动。
- 演示模式的进度与收藏标「本机 · 演示」，不会显示成「已同步」——只有实例确认过的条目才会显示「已同步」。
- 15/16/21 的豆瓣条目是**外部公网数据**；外网不可达时页面显示「发现页没有加载成功」与重试，不伪造条目（契约测试会把这类外部检查记为 skip）。
- 豆瓣图片在本机没有带 Referer，部分海报会回落到标题卡（显示「豆瓣」字样），这是当前实现的真实降级，不是数据缺失。
- 未在这个尺寸以外验证：多屏、100%/200% DPI、最大化、HDR、硬件解码；0.4.0 的窄窗只实测 1123×593 pt。

复现方式（演示）：`MOONTV_DATA_DIR=<临时目录> MOONTV_MEDIA_DIR=<仓库>/apps/desktop-nsh/media` 启动 exe，进入演示模式。

复现方式（隔离实例）：先运行 `node apps/desktop-nsh/tests/contract/isolated-run.mjs` 验证契约；需要长期实例截图时，用同一次性的 SQLite/夹具源启动本地实例（不连接生产实例、不读 `.data`）。截图为窗口级截图（PrintWindow，回退到屏幕区域复制）。
